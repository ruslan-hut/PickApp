# Google Play — матеріали сторінки (UK)

**Пакет:** ua.com.programmer.pick
**Назва (≤30):** Pick

## Короткий опис (≤80)
Складський ТСД: збирання, приймання, інвентаризація зі сканером

## Повний опис (≤4000)
Pick — професійний застосунок для термінала збору даних (ТСД), створений для автоматизації складських операцій. Допомагає компаніям пришвидшити збирання замовлень, приймання товару та інвентаризацію за допомогою сканування штрихкодів.

**Працює офлайн**
Усі операції виконуються локально на пристрої та зберігаються навіть без зв'язку. Зміни автоматично синхронізуються із сервером, щойно з'являється мережа, — робота на складі не зупиняється.

**Ключові можливості:**
• Збирання замовлень, приймання товару та інвентаризація в одному застосунку
• Сканування апаратним сканером ТСД або камерою (підтримка штрихкодів, GS1 DataMatrix та QR-кодів)
• Офлайн-режим: дані зберігаються локально й синхронізуються автоматично
• Ролі користувачів: комірник, кур'єр, адміністратор
• Контроль одночасної роботи з документами для уникнення конфліктів
• Інтеграція з ERP через проміжний сервер за REST API
• Журнал подій для діагностики та технічної підтримки

**Для кого**
Для складів, торгових і дистриб'юторських компаній, що використовують ТСД-пристрої та прагнуть пришвидшити логістику, зменшити кількість помилок і працювати в реальному часі.

Pick працює у зв'язці з вашою обліковою системою через проміжний сервер. Для роботи потрібен доступ до сервера вашої компанії.
